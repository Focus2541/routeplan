# เส้นทางประหยัดเวลา (routeplan) — v1.21

เว็บแอปจัดลำดับสถานที่ให้ไปได้มากที่สุดใน 1 วัน หรือแบ่งเป็นทริปหลายวัน

- ใส่เวลาออกเดินทาง / เวลาที่ต้องเสร็จ และเวลาเปิด-ปิดของแต่ละที่
- คำนวณลำดับที่ใช้เวลาน้อยที่สุด (เวลาเดินทางจริงจาก OSRM) ตัดจุดที่สำคัญน้อยออกก่อนถ้าเวลาไม่พอ
- เปิดนำทางทั้งเส้นทางใน Google Maps ได้ในคลิกเดียว
- เช็คพยากรณ์ฝน (Open-Meteo), แนะนำจุดพักรถ/ที่พัก (OpenStreetMap)
- ฟรี ไม่ต้องมี API key ข้อมูลบันทึกไว้ในเบราว์เซอร์ของผู้ใช้เอง

ไฟล์เดียว `index.html` — เปิดผ่าน GitHub Pages ได้เลย

## เวอร์ชัน
เลขเวอร์ชันและประวัติการอัปเดตอยู่ใน `index.html` (`APP_VERSION` และ `RELEASES`) แตะป้าย v ข้างชื่อแอปเพื่อดู
